# pin-macos 测试素材

给原生客户端（`pin-macos/`）批次 C 及之后的采集闭环做导入与显示测试用。

## 规矩

- **只在本分支（`native/pin-macOS/canvas-kernel-a`）使用**：不随产品发布、不进 App 包、
  不用于任何对外材料。
- 这些是**素材**不是**交付物**：删掉不影响构建与自检。自检与快照**一律**在临时目录里
  用合成素材跑，不读这里（避免"测试结果取决于本机恰好有哪些图"）。
- 命名：`pin-macos-test-NN-<内容>.<扩展名>`，`NN` 是两位序号。
- 派生文件（为覆盖格式/方向/损坏场景专门转出来或改造的）文件名带 `derived-`。
  **派生文件不能当"真实文件"用**：它们只用来验证代码分支，不构成"真实世界的文件
  长这样"的证据。
- 原始文件**不改字节、不重命名内容**——导入测试要验的就是"原样保存、原样显示"。

## 为什么不用聊天里上传的那份

上传通道会把图片**转码成 JPEG 并封顶到 2000 点**（实测：一张 1170×2532 的截图到达时
已是 924×2000 的 JPEG）。格式、尺寸、EXIF 方向都会失真——而这三样正是本轮要验的，
所以必须用原始文件。
