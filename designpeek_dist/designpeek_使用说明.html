产品定位

DesignPeek 是一款专为交互设计师打造的竞品截图管理与分析工具。它解决了一个高频痛点：设计师每天在手机上截取大量竞品 App 截图，但截图散落在相册里难以整理，更难以系统性地对比分析。

通过 iPhone 快捷指令 + Mac 本地服务 + AI 视觉分析 的组合，DesignPeek 实现了从截图收集到分析报告的完整闭环。所有数据存储在本地，无需上传云端。

核心能力

📱
一键收集
iPhone 控制中心一键上传截图，自动按 App 归类命名
📂

🤖

快速上手

Mac 端

1
首次安装
终端进入项目目录，运行 ./setup.sh 安装依赖
2
配置 API Key
编辑 .env 文件，填入 Gemini API Key（免费获取：aistudio.google.com/apikey）
3
启动服务
运行 ./start.sh，终端会显示局域网 IP 地址，记下来
4
打开管理页面
浏览器访问 http://localhost:8765

iPhone 端

1
安装快捷指令
在 iPhone 浏览器打开：
https://www.icloud.com/shortcuts/e6e454840f5b4efe9285b8454447a309
2
填入 Mac IP 地址
打开快捷指令编辑，找到「文本」步骤，把 IP 改成 Mac 启动时显示的地址（如 192.168.1.10）
3
添加到控制中心
iPhone 设置 → 控制中心 → 添加此快捷指令，之后下滑即可一键上传
注意：Mac 和 iPhone 需要连接同一个 Wi-Fi 网络才能传输截图。AI 分析使用 Google Gemini API，免费额度每天约 1500 次。

四种采集方式

除了 iPhone 一键上传，DesignPeek 还支持安卓直连、边逛边截、电脑本地上传等多种采集方式，按手头设备和场景灵活选择。

🍎
iPhone 一键上传
配置好快捷指令后，控制中心下滑一键发送截图到 Mac（见上方「快速上手 - iPhone 端」）
📸
安卓截图
数据线连接安卓手机，点「安卓截图」抓取当前屏幕，自动识别 App 并归类命名
🎬
边逛边截
安卓连接后开启，边刷 App 边自动截图，自动跳过重复页面；支持「定时」与「屏幕变化触发（免提）」两种模式
💻
本地上传
在电脑上直接选择图片文件批量上传，适合整理已有的截图素材
注意：安卓相关功能（安卓截图 / 边逛边截）需用数据线连接安卓手机并开启 USB 调试，Mac 上需安装 adb（Android 调试桥）。iPhone 一键上传与本地上传无需 adb。

典型使用流程

1
收集截图
在手机上刷竞品 App，看到好的设计就截图，滑出控制中心点击快捷指令上传
2
创建项目
在 Mac 管理页面创建分析项目（如「公益频道竞品分析」），批量导入相关截图
3
AI 分析
点击分析项目，AI 自动识别每张截图的触点，确认调整后生成对比报告
4
查看报告
获取平台对比、触点分析、设计亮点和综合建议，直接用于设计决策
