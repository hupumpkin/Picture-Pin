📱 手机上传设置指南

配置好后，在 iPhone 控制中心一键发送截图到 Mac

1
在 Mac 上启动服务
终端运行 python server.py，记下显示的 IP 地址（如 192.168.1.10）
2
安装快捷指令
在 iPhone 上复制此链接在浏览器打开安装：
https://www.icloud.com/shortcuts/e6e454840f5b4efe9285b8454447a309
3
配置 Mac IP 地址
打开快捷指令编辑，找到「文本」步骤，将 IP 地址改成第 1 步记下的地址
4
添加到控制中心
iPhone 设置 → 控制中心 → 添加此快捷指令，下滑控制中心即可一键上传
提醒：Mac 和 iPhone 需要连接同一个 Wi-Fi 网络才能传输。
