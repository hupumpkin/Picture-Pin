# iPhone 截图自动传输 — 最终配置

截图 → 敲两下手机背面 → 自动以「App名_时间」传到 Mac。

---

## 快捷指令（5 个动作）

| 顺序 | 动作 | 说明 |
|------|------|------|
| 1 | **获取最新照片** | 数量 1 |
| 2 | **获取当前 App** | 获取正在运行的 App 名称 |
| 3 | **文本** | 输入 `http://你Mac的IP:8765/api/upload/image` |
| 4 | **获取 URL 内容** | URL 选「文本」，方法 POST，请求体 文件，文件选「最新照片」 |
| 5 | （第 4 步展开「显示更多」→ 标头 → 添加 `X-App-Name`，值选「当前 App」） | |

## 背面敲击

设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「传到 Mac」

## 使用

1. 竞品 App 内截图
2. 食指敲两下手机背面
3. Mac 上 `screenshots/{App名}/` 文件夹直接收到，文件名 `微信_20260528_143021.png`
