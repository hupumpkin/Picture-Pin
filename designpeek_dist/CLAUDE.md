# DesignPeek — 给 AI 助手的安装与运行指南

> 这是一份给 Claude Code / Codex 的"安装剧本"。当用户(设计师同事)说"帮我把这个工具装好并启动"时,请严格按本文引导他们完成。用户大概率**不懂代码、不懂终端**,请用平实的中文一步步带,每一步先说要做什么、再执行。

## 这是什么

DesignPeek(设计透视)是一款给交互设计师用的**竞品截图管理与分析工具**:把手机/电脑上的竞品 App 截图收集到一起,用 AI 自动按触点分类、生成跨平台对比分析报告。本地 Python 服务 + 浏览器管理页面,数据全部存在本地。

## 安装流程(请按顺序引导用户)

### 第 1 步:运行安装脚本
在项目目录下执行:
```
./setup.sh
```
它会自动创建 Python 虚拟环境、安装依赖、生成 `.env` 配置文件。若提示权限问题,先 `chmod +x setup.sh start.sh`。

### 第 2 步:配置 AI Key(关键,需主动询问用户)
截图分析需要一个 AI 服务。**请主动问用户用哪一种**,不要替他默认:

> "截图分析需要一个 AI Key,你用哪种?
> 1. 公司发的 Claude Key
> 2. 公司发的 GPT Key
> 3. 自己的 Google Gemini Key(免费,但需 Google 账号、可能要梯子)"

根据回答,编辑 `.env` 文件(已由 setup.sh 从 `.env.example` 生成):
- **选 Claude** → 设 `AI_PROVIDER=claude`,填 `ANTHROPIC_API_KEY`。若用户的 Key 需走公司网关,询问其网关地址填入 `ANTHROPIC_BASE_URL`(不确定可用 `o2` 查公司 LLM 网关信息)。
- **选 GPT** → 设 `AI_PROVIDER=openai`,填 `OPENAI_API_KEY`,并设 `OPENAI_BASE_URL` 为公司网关地址(参考 `.env` 注释,以团队实际下发为准)。
- **选 Gemini** → 设 `AI_PROVIDER=gemini`,填 `GEMINI_API_KEY`(申请页 https://aistudio.google.com/apikey )。

`.env` 文件里每种方案都有注释,只需填用户选中的那一种,其余留空。

### 第 3 步:启动服务
```
./start.sh
```
终端会打印两个地址:**Mac 管理页面**(http://localhost:8765 )和 **iPhone 快捷指令 URL**。让用户记下后者(配手机上传时要用)。

### 第 4 步:打开管理页面
引导用户用浏览器打开 http://localhost:8765 ,确认能看到界面即安装成功。可让他用左下角"💻 本地上传"传一张图片、点分析,验证 AI Key 配置正确。

### 第 5 步(可选):配置 iPhone 一键截图上传
若用户想用 iPhone 把竞品截图一键传到 Mac,**主动一步步带他做**(手机操作 AI 没法代点,所以请口述引导、每步等用户回"好了"再继续)。先确认用户记下了第 3 步终端打印的 iPhone 快捷指令 URL(形如 `http://192.168.x.x:8765/api/upload`)。

引导话术(逐步进行):

1. **安装快捷指令**:"在 iPhone 浏览器打开这个链接,点『添加快捷指令』:
   `https://www.icloud.com/shortcuts/e6e454840f5b4efe9285b8454447a309`"
   (这是现成模板,装上后只需改一个地址。)
2. **改成你自己的 Mac IP(最关键一步,务必提醒)**:"打开快捷指令 → 编辑,找到『文本』那一步,把里面的 IP 地址换成刚才终端显示的那串(比如 `192.168.1.10`),其余别动。" 强调:不改这一步,手机截图传不过来。
3. **(若用户的快捷指令是空白/需手动搭)** 按以下 5 个动作依次添加(顺序不能乱):
   - ① 获取最新照片(数量 1)
   - ② 获取当前 App(取正在运行的 App 名)
   - ③ 文本 = `http://你的MacIP:8765/api/upload/image`
   - ④ 获取 URL 内容:URL 选「文本」,方法 POST,请求体选「文件」,文件选「最新照片」
   - ⑤ 在第 ④ 步展开「显示更多」→ 标头 → 添加 `X-App-Name`,值选「当前 App」
4. **加到控制中心 / 背面轻点**:"iPhone 设置 → 控制中心,把这个快捷指令加进去;或设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选这个快捷指令。之后截图后下滑控制中心点一下(或敲两下手机背面)就自动传到 Mac。"
5. **验证**:让用户在手机上随便截张图触发一次,回到 Mac 管理页面查看「新添加截图」里是否出现这张图。

> 前提:Mac 和 iPhone 连同一个 Wi-Fi;`./start.sh` 服务保持运行中。图文版同样见 `designpeek_使用说明.html`。

## 安全红线(务必遵守)
- **绝不**把 `.env` 文件提交到 git、发给他人或贴到聊天里——它含用户的真实 API Key。
- 不要读取用户 `screenshots/` 里的截图内容并外传。
- 不要把用户的 Key 写进任何会被分享的文件(只能写在本地 `.env`)。

## 功能用法
完整功能(四种采集方式、项目分析、OCR 搜索、收藏备注等)见项目内 `designpeek_使用说明.html`,用浏览器打开即可。

## 环境说明
- 面向 macOS(OCR 文字识别依赖 macOS 系统能力,其他系统会自动跳过,不影响分析)。
- 需要 Python 3。`setup.sh` 用系统 `python3` 建虚拟环境。
